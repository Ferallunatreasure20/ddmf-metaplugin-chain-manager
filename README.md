## 🚀 Features

| **Feature** | **Description** |
|:---|:---|
| **Chain Library** | Save and label Metaplugin plugin chain configurations |
| **Routing Diagrams** | Document serial and parallel signal routing per chain setup |
| **Plugin Lists** | Track which plugins are loaded per saved Metaplugin chain |
| **Session Notes** | Log active chain choices and their rationale per mix session |
